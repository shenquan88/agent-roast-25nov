Entry for make.fun's **Roast Your Own Agent**: one line, at most 200 characters, roasting the
entrant's own agent.

> My agent thought for nine minutes, then asked me to clarify the task. It had written the task. In bold. At the top.

`main.ts` writes that line to `/output/entry.txt`, which is the whole entry.

## Run it

``sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
``

Node 22.18 or later runs the TypeScript as it is, with nothing to install.
`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside the grader.
